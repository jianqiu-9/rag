# Agent 验收资料

> 人工编写的合成测试资料，不代表真实面试频率或外部权威资料。

## 21. 工具调用与普通文本回答有什么区别？
A: 工具调用把结构化参数交给外部函数执行，普通文本回答仅生成文本。

## 22. 为什么工具参数需要校验？
A: 模型输出可能缺字段或类型错误，执行前应按参数契约进行校验。

## 23. 什么是工具调用白名单？
A: 白名单明确允许使用的工具集合，避免执行未经授权的能力。

## 24. Agent 如何处理工具执行失败？
A: 区分可重试与不可重试错误，限制重试次数，并向用户报告失败原因。

## 25. 为什么需要限制 Agent 执行步数？
A: 步数上限可防止循环调用和失控的耗时或费用。

## 26. 什么是幂等操作？
A: 同一操作重复执行不会产生额外有效副作用，例如相同哈希文件不重复入库。

## 27. 什么是短期会话状态？
A: 短期状态保存当前任务所需的上下文，服务于本次会话的后续步骤。

## 28. 工具返回的文本可信任吗？
A: 不能默认信任。工具返回内容是数据，不应自动获得系统指令的优先级。

## 29. 什么是提示注入？
A: 提示注入试图把资料中的指令当成系统命令，诱导模型偏离原任务。

## 30. 如何降低知识库中的提示注入影响？
A: 把资料标记为不可信数据，限制工具能力，并在服务端校验结果和引用。

## 31. 为什么不把 API Key 放进前端？
A: 浏览器代码和请求可被查看，密钥应由后端读取并用于远程服务调用。

## 32. 为什么要设置模型调用总超时？
A: 总超时约束一次用户请求中的全部调用与退避，避免多次重试无限延长等待。

## 33. 哪些模型调用错误适合重试？
A: 网络临时故障、限流和服务端临时错误可在总预算内有限重试。

## 34. 鉴权失败需要自动重试吗？
A: 通常不需要，应该检查密钥或配置，重复相同调用无法修正鉴权问题。

## 35. 结构化模型输出是否还需要服务端检查？
A: 需要，格式有效不代表引用真实或业务规则得到满足。
